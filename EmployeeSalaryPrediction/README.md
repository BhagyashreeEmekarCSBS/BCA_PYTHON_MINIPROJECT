# Employee Salary Prediction System

## Project Overview
This project predicts employee salaries based on years
of work experience using Machine Learning.

## Objectives
- Analyze employee salary data.
- Visualize the relationship between experience and salary.
- Train a Linear Regression model.
- Evaluate model performance.
- Predict salary for new employees.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm
Linear Regression

## Dataset
Salary_Data.csv

## How to Run
1. Install Python.
2. Install required libraries:
   python -m pip install pandas numpy matplotlib seaborn scikit-learn
3. Run the program:
   python salary_prediction.py

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Conclusion
The system learns the relationship between years of
experience and salary and uses the trained model to
estimate salaries for new employees.
