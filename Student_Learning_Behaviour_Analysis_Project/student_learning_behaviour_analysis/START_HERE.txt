START HERE
1. Extract this ZIP file.
2. Open the extracted folder.
3. Click the File Explorer address bar, type cmd, and press Enter.
4. Type: py -m pip install -r requirements.txt
5. After installation finishes, type: py main.py
6. Open the outputs folder to see graphs and CSV results.

If the command 'py' does not work, try 'python' instead.
The included student dataset is synthetic sample data for demonstration.
