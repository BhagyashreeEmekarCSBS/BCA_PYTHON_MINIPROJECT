# Student Learning Behaviour Analysis System

A beginner-friendly Python mini project for analyzing student study habits and academic performance.

## Features
- Loads a student performance CSV dataset with Pandas.
- Performs exploratory data analysis (EDA) and descriptive statistics.
- Creates a final-marks distribution graph, correlation heatmap, and study-hours scatter plot.
- Uses StandardScaler and K-Means clustering to group students by learning/performance indicators.
- Saves cluster profiles and student-specific academic recommendations.

## Requirements
- Windows 10/11
- Python 3.11.9 (or compatible Python 3.11)
- Internet connection for the first installation of Python packages

## Run on Windows
1. Extract the ZIP file.
2. Open the extracted `student_learning_behaviour_analysis` folder.
3. Click the File Explorer address bar, type `cmd`, and press Enter.
4. Install dependencies:

   ```bat
   py -m pip install -r requirements.txt
   ```

5. Run the program:

   ```bat
   py main.py
   ```

If `py` is not recognized, try `python -m pip install -r requirements.txt` and `python main.py`.

## Files
- `main.py`: complete analysis program.
- `student_performance.csv`: included sample dataset (synthetic demonstration data).
- `requirements.txt`: Python package list.
- `PROJECT_REPORT.md`: editable mini-project report.
- `outputs/`: created automatically when the program runs.

## Dataset note
The included dataset is synthetic and intended for demonstrating the workflow. It is not official student data and should not be represented as real research data. Replace it with an institution-approved dataset for a real study. Do not include identifying student details without appropriate permission.

## Interpretation note
Correlation indicates association, not causation. Cluster numbers are labels, not rankings. Recommendations are simple rule-based suggestions and should be reviewed by educators before use.
